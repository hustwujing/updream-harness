# updream-harness mark

Original project artwork: a mint U rising into an arrow on a dark green rounded tile.

`updream-mark.svg` is the source used by the browser favicon, navigation brand and welcome screen. `favicon-32.png` and `apple-touch-icon.png` are 32 px and 180 px renders of that same SVG for browser fallback and saved home-screen shortcuts. Regenerate both PNGs when changing the SVG. Vite fingerprints all three deployed assets.

These are product brand assets; individual Harness identities retain their own official icons in the adjacent `harness/` directory.
