# Updream Conductor mark

The Conductor mark combines three converging execution nodes with a warm baton
on a dark green rounded tile. It represents one user-directed system
coordinating Harnesses, tools and external providers.

`conductor-mark.svg` is the source used by the browser favicon, navigation
brand and welcome screen. `favicon-32.png` and `apple-touch-icon.png` are 32 px
and 180 px renders of that same SVG for browser fallback and saved home-screen
shortcuts. Regenerate both PNGs when changing the SVG. Vite fingerprints all
three deployed assets. `updream-mark.svg` remains only as historical artwork.

These are product brand assets; individual Harness identities retain their own official icons in the adjacent `harness/` directory.
