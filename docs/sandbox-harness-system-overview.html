Sandbox Harness Platform

独立部署单元、每 Turn 动态执行资源与项目专属持久层

deployment overview
API + Broker / Gateway / Runtime / OpenSandbox

橙色：我们的代码

Web UI、sandbox-harness-api、sandbox-harness-gateway、sandbox-harness-network、sandbox-harness-runtime 都是本项目代码；专属 PostgreSQL 的数据与日志也归本部署管理。

灰色：外部或共享能力

OpenSandbox Service、Sandbox 实例、Redis、BOSS/S3、模型 Provider 是共享或外部能力；系统通过 API、namespace 和 Token 使用它们。

网络边界职责

Network Rule 只在宿主机防火墙层放行 Sandbox 网段到 Gateway 的 28600/28601；Token 校验、目标过滤和模型路由仍由 Gateway 完成。
