## Defect And Affected Rerun

XDB04 found that a terminal result from an in-process Provider entered the
external-cancel helper, which had no adapter object for that Provider and
therefore stored `worker_error/UNKNOWN`. The shared MediaWorker transition now
discards a known terminal result as `cancelled` before publication. Providers
with a durable external job ID and cancel adapter still receive one remote
cancel request. The focused MediaWorker, repository and handoff suites passed;
P08 reran successfully with one cancelled member and two independent successes.
P18 reran on `a59df96` after the Runtime Code Bundle and Sandbox Inspector
update; checkpoint restore, takeover and terminal access passed.
